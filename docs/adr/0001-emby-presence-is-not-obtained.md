# 0001 — Emby 存在的媒体不等于已获取

- 状态：已采纳
- 日期：2026-11-04

## 背景

接入 Emby 后，用户希望「Emby 里已经有的集/电影就不要再去搜索」。最省事的实现是把 Emby 命中的集直接写成 `Obtained: true`，这样覆盖判断、详情页、巡检都会自动认为它已入库。

但 `Obtained` 在本系统里有一个严格含义：媒体已经落到**本系统追踪的网盘**上并被读回验证。它决定跨盘副本归属、网盘徽章、以及「哪个盘能收齐」的分配判断。把 Emby 的媒体写进这个集合，会让系统声称某块网盘上有一份并不存在的文件。

## 决策

Emby 命中是一个独立状态 `AvailableInEmby`：

- 它参与「搜索需求」的计算，并从缺集判断与巡检中排除；
- 它**不**写入 `Obtained`，也不产生 `episode_copies` / 网盘徽章；
- 详情页显示独立的 `Emby` 状态；季徽章把它算作已覆盖；
- Emby 不可达时按「不知道」处理（fail-open），不阻塞获取。

## 后果

- 网盘与 Emby 两个事实源保持分离；用户仍能看到「这集在 Emby，但不在网盘」。
- 覆盖判断多了一条并集逻辑（`priorObtained ∪ emby` 只用于搜索需求）。
- 如果 Emby 里删掉了某个媒体，下一次运行会把对应状态重新算回缺失并恢复搜索。
